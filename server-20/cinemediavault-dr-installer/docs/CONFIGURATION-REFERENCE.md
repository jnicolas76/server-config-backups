# CineMediaVault configuration reference

Generated from the schema in `installer/config/schema.py` at installer version 2.3.0 (configuration schema v1).
Do not edit this file by hand; run `tools/gen-config-reference.py` instead.

## How configuration is loaded

Settings are resolved in this order, later winning over earlier:

1. the defaults in this document,
2. `/etc/cinemediavault/cinemediavault.yaml`,
3. environment overrides named `CMV_<SECTION>_<KEY>`, for example
   `CMV_NETWORK_HTTPS_PORT=5443`.

An environment name that matches no setting is an error rather than being
ignored, so a typo is reported instead of silently doing nothing.

Every value is validated by the same code whichever route it arrives by,
so the browser wizard and an unattended file cannot disagree.

## Secrets

Values marked **secret** never appear in `cinemediavault.yaml`. The
installer moves them to `/etc/cinemediavault/secrets.env`, mode 0640,
owned `root:cinevault`. You may put real values in a configuration file
for an unattended install; the installer moves them out and blanks them
on the first write.

The administrator password is never stored at all. It is converted to a
PBKDF2-SHA256 hash and the plaintext is discarded immediately.

| `poster_rotation_seconds` | int | `21600` | range 60 to 604800 |

**`ops.log_level`**

How much detail the installer and services write to their logs.

**`ops.log_retain_days`**

Days of rotated logs to keep before they are deleted.

**`ops.db_backup_time`**

Local time of the nightly database backup. Keep it clear of the EPG collection window so the two do not compete for disk.

**`ops.db_backup_keep`**

Number of database backups to retain. Older ones are pruned automatically; at least one is always kept.

**`ops.health_check_enabled`**

Run a health probe every minute and restart the service if it stops answering.

**`ops.health_failure_threshold`**

Consecutive failed probes before a restart. Do not set this to 1: a single stalled probe on a busy server is normal, and restarting on it would interrupt playback and mask real failures.

**`ops.health_restart_cooldown_seconds`**

Minimum seconds between two health-triggered restarts. Stops a restart storm when the service dies again immediately.

**`ops.session_days`**

How long a signed-in browser session stays valid.

**`ops.poster_rotation_seconds`**

How often the home and sign-in background artwork changes. The selection is cached so a restart does not rotate it early.

### `paths`

Where the installer puts things. Change only if you have a reason to; every other document assumes the defaults.

| Setting | Type | Default | Constraints |
|---|---|---|---|
| `install_root` | str | `/opt/cinemediavault` | absolute path |
| `config_root` | str | `/etc/cinemediavault` | absolute path |
| `state_root` | str | `/var/lib/cinemediavault` | absolute path |
| `log_root` | str | `/var/log/cinemediavault` | absolute path |
| `cache_root` | str | `/var/cache/cinemediavault` | absolute path |
| `service_user` | str | `cinevault` | - |
| `service_group` | str | `cinevault` | - |

**`paths.install_root`**

Where the application itself is installed. Root-owned and never writable by the service.

**`paths.config_root`**

Configuration and secrets.

**`paths.state_root`**

Databases, generated metadata, artwork and backups.

**`paths.log_root`**

Log files.

**`paths.cache_root`**

Regenerable caches: HLS segments, subtitles, mobile downloads. Safe to delete when the service is stopped.

**`paths.service_user`**

Unprivileged system account the services run as.

**`paths.service_group`**

Group that may read the secret files.
