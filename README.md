# Server Configuration Backups

Sanitized configuration and application-source snapshots for:

- `wsl/` - WSL transcode orchestration and portable software sources
- `server-20/` - CineMediaVault, BookVault, launchers, installers, Open WebUI, and the network tool gateway
- `server-134/` - Docker Compose, Homepage, and Project Zomboid configuration
- `ollama-gpu/` - GPU Ollama on server `.232`, Open WebUI cutover files, and Proxmox resource notes

Runtime databases, credentials, API tokens, webhook URLs, private keys, media,
downloaded artwork, caches, logs, generated archives, and model weights are intentionally not
tracked. Machine configuration snapshots may contain paths and LAN addresses,
but no authentication material.
